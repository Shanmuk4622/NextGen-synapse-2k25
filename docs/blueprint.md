# **App Name**: Course Central

## Core Features:

- User Authentication: Enable user registration and login with different roles (student/teacher).
- Course Creation: Allow teachers to create courses with title, description, and duration.
- Course Listing: Display a list of available courses for students to view.
- Course Enrollment: Enable students to enroll in courses and view their enrolled courses.
- Assignment Submission: Allow teachers to create assignments and students to submit them.
- Grading System: Implement a grading system for teachers to grade assignments and students to view grades.
- AI-Powered Personalized Learning Path: AI tool that provides course recommendations, or suggests alternative learning resources and tracks student's understanding, offering targeted help to address their individual gaps. It may incorporate additional factors in its reasoning, like current trends or overall knowledge assessments.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to convey knowledge and professionalism.
- Background color: Light lavender (#E6E6FA), offering a soft and calm backdrop.
- Accent color: Golden yellow (#FFD700) to highlight important actions.
- Body font: 'PT Sans', sans-serif.
- Headline font: 'Playfair', modern serif, suitable for headlines.
- Use consistent and clear icons to represent different course categories and actions.
- Implement a clean and intuitive layout for easy navigation and content discovery.
- Use subtle transitions and animations to enhance user experience.
